# 🧮 Calculadora Inteligente em Python

Projeto desenvolvido em Python com o objetivo de praticar lógica de programação, modularização e boas práticas de desenvolvimento.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Potenciação
- Raiz Quadrada

## Tecnologias

- Python 3
- VS Code

## Estrutura do projeto

```
main.py
operacoes.py
utils.py
```

## Como executar

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta:

```bash
cd python-calculadora-inteligente
```

Execute:

```bash
python main.py
```
